# Intervalltimer

Webbapp för egna intervallpass med löpning och vila. Nedräkning, ljudsignaler, uppläst röst och sparade favoritpass. Fungerar offline och kan installeras på hemskärmen.

**Installera på iPhone:** öppna sidan i Safari → Dela → Lägg till på hemskärmen.
**Android:** öppna i Chrome → menyn → Installera app.

Pass och favoriter sparas lokalt i webbläsaren på enheten.

Vid ändring i `index.html`: höj `CACHE`-versionen i `sw.js`.
